
## Pull 

Сценарий выполнения операции pull: 

1. Получения запроса от пользователя
2. Отправка запроса на инсталляцию
3. Получение набора исходников и их чексумм от инсталляции 
4. Сверка набора с запросом - в случае отсутствия какого либо исходника будет выброшена ошибка
5. Сохранение чексумм и исходников

## Sync Check 

Сценарий выполнения операции sync check: 

1. Получения запроса от пользователя
2. Поиск локальных исходников по запросу 
3. Сверка набора с запросом - в случае отсутствия какого либо исходника будет выброшена ошибка
4. Получение чексумм по исходников с инсталляции 
5. Сверка каждой чексуммы. В случае если чексуммы равны, либо чексуммы нету на сервере - все окей, иначе - конфликт

## Push

Сценарий выполнения операции push: 

1. Получение запроса от пользователя
2. Поиск локальных исходников по запросу 
3. Сверка набора с запросом - в случае отсутствия какого либо исходника будет выброшена ошибка
4. Если признак force = true не передан - выполняется sync check. В случае конфликта при выполнение sync check операция будет прервана.
5. Отправка локального состояния исходников на инсталляцию. Там будет выполнена компиляция, то есть загрузка может быть прервана, если компиляция не пойдет успешно.
